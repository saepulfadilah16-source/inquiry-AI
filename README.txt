# AI DEEP INQUIRY LAB — Demo Presentasi

## Cara menjalankan
1. Buka folder ini di VS Code.
2. Buka `index.html`.
3. Klik kanan → **Open with Live Server**.
4. Browser akan membuka aplikasi.
5. Klik tahap 1–7 dan isi jawaban untuk menunjukkan alur Pembelajaran Mendalam.

Tidak membutuhkan API, database, atau internet untuk simulasi AI.
Respons AI pada Tahap 5 adalah simulasi lokal berbasis JavaScript.

## Struktur
- `index.html` — struktur halaman
- `style.css` — desain/responsif
- `script.js` — interaksi 7 tahap + AI demo

## Alur
AMATI → TANYAKAN → CARI BUKTI → ANALISIS → DIALOG AI → KEPUTUSAN → REFLEKSI

## Catatan presentasi
Kalimat kunci:
**“AI membantu proses berpikir, tetapi tidak mengambil alih proses berpikir.”**
